# Content Integrator Microagent

- Fill each section with real or sample content, images, and interactive elements.

- Optimize images and media for performance.
- Add alt text, ARIA labels, and keyboard navigation.
- Output the completed site, ready for export.

Call the `deployment-export` microagent to build and export the site.
