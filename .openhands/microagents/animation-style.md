# Animation & Style Microagent

For each React component:

- Apply vertical slide-in/out and fade animations using Framer Motion or GSAP.
- Use TailwindCSS or styled-components for responsive, elegant styling.
- Ensure color contrast and font choices match the planned palette.
- Add subtle micro-interactions (hover, focus, tap).
- Output the styled component, ready for integration.

Call the `static-site-generator` microagent to assemble the site.
